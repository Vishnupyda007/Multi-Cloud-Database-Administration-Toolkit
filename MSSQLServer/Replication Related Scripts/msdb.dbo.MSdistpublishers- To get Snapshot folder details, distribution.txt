select * from msdb.dbo.MSdistpublishers


--------------------
?? What it shows:
Publisher name: The SQL Server instance that is publishing data.
Distributor: The SQL Server instance that manages the distribution of replication data.
Security settings: How the publisher connects to the distributor.
Replication type: Whether it's transactional, snapshot, or merge replication.
?? When to use this:
When you're troubleshooting replication issues.
When you want to verify or audit replication configuration.
When you're scripting or automating replication setup.
