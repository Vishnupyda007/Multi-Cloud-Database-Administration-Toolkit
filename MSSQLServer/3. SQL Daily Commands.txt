>>>>>>>>>>>>>INDEX rebuild performance improvement query<<<<<<<<<<<<
> Fragmentation is exists when indexes have pages in which the logical ordering, based on the key value, 
does not match the physical ordering inside the data file. Fragmentation is of two types> Internal and external fragmentation.
>> By using the system function   "sys.dm_db_index_physical_stats" -   you can detect fragmentation in a specific index, all indexes on a table or indexed view, all indexes in a database, or all indexes in all the databases. 
It can also provide info on each partition.
Note: We have to rebuild the index when the fragmentation is >30%. We can do index rebuild for a table through UI also but while doing UI method it will ask online or offline rebuild.
If fragmentation is >5% and <=30% then use reogranize the index. Reorganize is always executed online.

  syx- ALTER INDEX ALL ON SchemaName.TableName REBUILD  or ALTER INDEX INXname ON SchemaName.TableName REBUILD

  syx- alter index all on schemaName.TblName Reorganize
