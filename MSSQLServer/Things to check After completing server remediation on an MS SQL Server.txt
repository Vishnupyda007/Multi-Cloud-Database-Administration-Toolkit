After completing server remediation on an MS SQL Server, it's important to perform a series of checks to ensure that the server is functioning correctly and securely. Here are some key things to consider:

1. **Verify Connectivity**: Ensure that the SQL Server instance can be accessed by the intended clients and applications.

2. **Check Services**: Confirm that all necessary SQL Server services are running as expected.

3. **Review Error Logs**: Examine the SQL Server error logs for any unusual entries that might indicate problems.

4. **Database Integrity**: Run `DBCC CHECKDB` on your databases to check for consistency errors and to ensure the logical and physical integrity of all the objects in the specified database².

5. **Backup Verification**: If backups were restored as part of the remediation, verify that they have been restored successfully and that the data is accurate.

6. **Security Settings**: Review the security settings and permissions to make sure they align with your organization's policies. You can use the SQL Server Vulnerability Assessment tool to scan for security issues and deviations from best practices³.

7. **Performance Metrics**: Monitor performance metrics to ensure that the server is operating within the expected parameters. Look for any significant changes in response times or resource usage.

8. **Scheduled Jobs**: Check the status of any scheduled jobs to confirm they are running as planned.

9. **System Databases**: Ensure that system databases (master, model, msdb, and tempdb) are intact and functioning properly.

10. **SQL Agent**: If SQL Server Agent is used, verify that it is running and that all jobs are executing successfully.

11. **Resource Utilization**: Monitor CPU, memory, disk I/O, and network usage to detect any bottlenecks or unusual activity.

12. **Update Statistics**: Update statistics to ensure the query optimizer has current information, which can help improve query performance.

13. **Review Configuration Settings**: Check the SQL Server configuration settings to ensure they are set according to the best practices and your organization's requirements.
