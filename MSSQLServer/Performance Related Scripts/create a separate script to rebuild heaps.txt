Heaps, which are tables without clustered indexes, can also experience fragmentation. However, the IndexOptimize procedure does not directly handle heap fragmentation. To address fragmentation in heaps, you can use the ALTER TABLE ... REBUILD statement.

Modifying the Script for Heaps
You can create a separate script to rebuild heaps. Here’s an example of how you can do it:

-- Rebuild heaps in the specified databases
DECLARE @DatabaseName NVARCHAR(128);
DECLARE @SQL NVARCHAR(MAX);

DECLARE db_cursor CURSOR FOR
SELECT name
FROM sys.databases
WHERE name IN ('Database1', 'Database2', 'Database3');

OPEN db_cursor;
FETCH NEXT FROM db_cursor INTO @DatabaseName;

WHILE @@FETCH_STATUS = 0
BEGIN
    SET @SQL = N'USE ' + QUOTENAME(@DatabaseName) + ';
    DECLARE @TableName NVARCHAR(128);
    DECLARE table_cursor CURSOR FOR
    SELECT t.name
    FROM sys.tables t
    JOIN sys.indexes i ON t.object_id = i.object_id
    WHERE i.type = 0; -- Heaps

    OPEN table_cursor;
    FETCH NEXT FROM table_cursor INTO @TableName;

    WHILE @@FETCH_STATUS = 0
    BEGIN
        EXEC(''ALTER TABLE '' + QUOTENAME(@TableName) + '' REBUILD'');
        FETCH NEXT FROM table_cursor INTO @TableName;
    END;

    CLOSE table_cursor;
    DEALLOCATE table_cursor;';

    EXEC sp_executesql @SQL;
    FETCH NEXT FROM db_cursor INTO @DatabaseName;
END;

CLOSE db_cursor;
DEALLOCATE db_cursor;
